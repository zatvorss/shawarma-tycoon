ШАУРМА МАГНАТ: ПУТЬ К МИЛЛИАРДУ v0.19 — Valour Games
==================================

УСТАНОВКА
1. Удали старые папки Assets/_Game и Assets/WebGLTemplates (если есть).
2. Распакуй архив в Assets (появятся Assets/_Game и Assets/WebGLTemplates/YandexGames).
3. Valour Games → Собрать игру. Game view: 1920x1080. Play.
(Сохранения v0.3 переносятся.)

v0.19 — ПОДГОТОВКА К ЯНДЕКС ИГРАМ
- Встроен SDK Яндекс Игр: шаблон страницы WebGLTemplates/YandexGames
  (подключает /sdk.js и YaGames.init()) + мост Plugins/WebGL/YandexGames.jslib.
  «Valour Games → Применить настройки WebGL» сам выбирает этот шаблон.
- LoadingAPI.ready() — когда появляется главное меню; GameplayAPI start/stop —
  начало дня / пауза / конец дня; game_api_pause/resume обрабатываются.
- Реклама только через SDK: полноэкранная — после итогов дня (логическая пауза),
  за награду — только по кнопке «… за рекламу». На время рекламы, при потере
  фокуса и по game_api_pause звук и игра стоят на паузе.
- Облачные сохранения (player.setData / getData): берётся более свежее из облака
  и локального. Сохранение в облако — не чаще раза в 5 сек и сразу при
  сворачивании. Гостевая игра без входа — прогресс сохраняется.
- Вход с Яндекс ID — только по кнопке в Лидерборде (с объяснением выгоды).
- Покупки только через SDK: цена и значок валюты из каталога, покупка сразу
  выдаётся, сохраняется и консумируется; при запуске неконсумированные покупки
  выдаются. Товара нет в каталоге — кнопки покупки нет. В редакторе — бесплатно.
- Лидерборды: «money» (заработано) и «served» (обслужено).
- Язык определяется через SDK автоматически.
- Страница: без прокрутки, swipe-to-refresh, выделения и меню по долгому тапу;
  без баннера Unity «WebGL на мобильных»; холст на весь экран.
- Админ-панель выключена. Убраны отсылки к политике: «Правительственная
  столовая» → «Бизнес-клуб», депутат/министр → банкир/директор, шейх → яхтсмен,
  гербы → картины.
- Также: «Рекорды» → «Лидерборд»; в пассе «+1 уровень за рекламу» без ожидания;
  доход сотрудников +50%; крылья самолёта стреловидные; поезд едет по рельсам;
  табло на вокзале убрано; слова больше не переносятся по буквам
  («Предпринимател-ь») — шрифт сам уменьшается, чтобы слово влезло целиком.

ЧТО СДЕЛАТЬ В КОНСОЛИ ЯНДЕКС ИГР
1. Сборка: Valour Games → Сделать WebGL-билд. Запаковать СОДЕРЖИМОЕ папки
   Builds/WebGL (index.html в корне архива, папка Build) в zip.
2. Черновик → «Игра использует облачные сохранения» — ВКЛЮЧИТЬ.
3. Лидерборды: создать два с техническими названиями  money  и  served
   (по убыванию; money — «Заработано», served — «Обслужено клиентов»).
4. Инап-покупки (все — активные):
     pass_plus  — «Шаурма-Пасс+», 99 ян: вторая дорожка наград пасса.
     staff_0 … staff_10 — «Повар: <название локации>»: наёмный повар в прошлом
       ларьке. Цены: 9, 19, 29, 39, 49, 69, 89, 109, 129, 149, 199 ян.
   Если покупки не нужны — просто не заводи их: кнопки покупки в игре скроются.
5. Ориентация: горизонтальная. Платформы: десктоп и мобильные (без ТВ —
   для ТВ нужно управление стрелками пульта).
6. Название в черновике должно совпадать с игрой: «Шаурма Магнат: Путь к миллиарду».
7. «Как играть» (можно вставить):
   Готовь шаурму на скорость. Нарезай мясо с вертела движением пальца/мыши,
   перетаскивай продукты на доску и стучи по ней, чтобы нарезать. Нажми на
   лаваш, затем на лотки с начинками — как в заказе клиента, и жми
   «Завернуть». Отдай заказ нажатием на клиента. Соус доливается, если
   зажать лоток. Выполняй цель дня, покупай улучшения, открывай новые
   локации и дойди до миллиарда! Управление — мышью или касанием.

v0.16
- ЭКОНОМИКА ПЕРЕСЧИТАНА на модели дня (комбо, жара, чаевые, золотые
  клиенты, прокачка). Темп дня считается от времени на заказ: во дворе
  шаурма собирается моментально — клиентов больше, терпение меньше,
  платят меньше; с упаковкой, грилем, фритюром и напитками — наоборот.

- Улучшения: все доступные на локации вместе стоят ≈45% заработанного
  там. Переезд: с 10-го дня (рынок — с 5-го, вокзал — с 8-го); по
  деньгам без рекламы: двор ≈7 дней, рынок ≈10, вокзал ≈12, дальше 13–15.
- «Места у прилавка» дороже; на экране улучшений — зелёные кресты прямо
  на боковых стенках ларька у окна, с ценой. В игре на стенке — без плюса.
- Второй ларёк: каждый уровень окупается за 10 дней его работы.
  Курьеры и тандыр стоят в «днях дохода» текущей локации.
- Тандыр: размер оптового заказа зависит от уровня (1-й — 3–6 лавашей).
- Напиток называется «Апельсин». Вокзал: вместо часов — перрон, рельсы,
  контактная сеть, табло и проезжающая электричка.
- Колесо удачи: в тексте реальный максимум монет. Новая реплика сюжета
